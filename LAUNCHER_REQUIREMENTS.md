# Kuban Launcher — требования

## Главный экран
Название игры, текущая и доступная версии, прогресс загрузки, скорость, оставшийся объём, кнопка действия: Скачать игру / Приостановить / Продолжить / Обновить / Играть / Восстановить.

## Установка и обновление
- Выбор папки для новой установки или подключение существующей папки с EXE.
- GitHub Releases: полный манифест файлов для каждой версии. Сравнение SHA-256 локальных файлов с манифестом; загрузка только отсутствующих или изменённых файлов.
- Приостановка и возобновление загрузки; при отсутствии поддержки Range сервером повторяется только текущий файл.
- Проверка размера и SHA-256, staging, резервные копии заменяемых файлов, откат при сбое. Запрет обновления при запущенной игре. Безопасные относительные пути, защита от выхода за каталог игры.
- Не затрагивать пользовательские сохранения и настройки в AppData. Запуск установленной игры без интернета.

## Новости и обновления
- Вкладка Новости: дата, заголовок, описание, необязательное изображение. Предлагаемый источник — news.json в публичном репозитории.
- Вкладка Обновления: версии, даты, списки изменений из GitHub Releases.
- Кэш последней успешной загрузки новостей для офлайн-режима.

## Приёмка
Проверить чистую установку, импорт существующей сборки, обновление одного файла без повторной загрузки неизменённых файлов, повреждённый файл, прерывание сети, откат и запуск офлайн на Windows.

Статус: требования к реализации, не готовый лаунчер. Не публиковать игровые бинарники до проверки прав на распространение ресурсов.
